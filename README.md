# 🌦️ Weather App

A simple and responsive weather application built using HTML, CSS, and JavaScript. This app fetches real-time weather data using the OpenWeatherMap API and displays important weather details for any city.

## 🚀 Features
- 🌍 Search weather by city name
- 🌡️ Real-time temperature (°C)
- 💧 Humidity information
- 🌬️ Wind speed (km/h)
- ☁️ Dynamic weather icons (Clouds, Clear, Rain, etc.)
- ⚡ Fast and lightweight

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- OpenWeatherMap API

## 📦 How to Use
1. Clone the repository
2. Add your API key from OpenWeatherMap
3. Run the project in browser
